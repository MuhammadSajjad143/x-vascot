The VASCOT datasets used in the paper:

- `Opcode 1915.xlsx` - Dataset I (1,915 verified contracts, safe / greedy)
- `Opcode 16469.xls` - Dataset II (sheet "Data", four classes) and Dataset II-r
  (sheet "Greedy and Non-Vulnerable", safe / greedy)

They come from the VASCOT study (Balci et al., 2026); please cite it if you use
them. Keep the file names as they are, because xvascot/config.py looks for them here.
